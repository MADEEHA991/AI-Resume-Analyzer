# 🤖 AI Resume Analyzer

An AI-powered web application that analyzes a resume against a job description and helps job seekers understand how well their resume matches the required skills.

The application extracts information from a PDF resume, detects relevant skills, compares them with the skills mentioned in a job description, calculates a resume match score, and provides personalized recommendations.

## 📌 Project Overview

Finding out whether a resume matches a particular job description can be difficult and time-consuming.

The AI Resume Analyzer simplifies this process by automatically analyzing the resume and job description and presenting the results in an easy-to-understand dashboard.

---

## ✨ Features

* **📄 Resume Upload:** Users can upload their resume in PDF format.
* **📝 Job Description Analysis:** Users can paste a job description into the application.
* **🎯 Resume Match Score:** Calculates a percentage-based match score between the resume and job requirements.
* **✅ Matching Skills:** Displays skills found in both the resume and job description.
* **❌ Missing Skills:** Identifies key skills mentioned in the job description that are missing from the resume.
* **📊 Skills Analysis:** Provides a detailed visual breakdown of detected skills.
* **📧 Contact Extraction:** Automatically extracts email addresses and phone numbers.
* **💡 Personalized Recommendations:** Generates actionable suggestions to help users optimize their resume.
* **📥 Download Analysis:** Export the generated analysis report for future reference.
