# 🤖 AI Resume Analyzer

An AI-powered web application that analyzes a resume against a job description to evaluate skill matches and provide optimization recommendations.

---

## 📌 Description

**AI Resume Analyzer** is an intelligent web application designed to bridge the gap between job seekers and job descriptions. By leveraging modern Natural Language Processing (NLP) techniques, the app analyzes a candidate's resume in PDF format alongside a target job description to evaluate skill alignment, calculate an accurate match score, and provide actionable suggestions for improvement.

### Key Features
* 📄 **PDF Resume Parsing**: Extracts plain text and key metadata directly from uploaded PDF resumes.
* 🎯 **Match Score Engine**: Calculates a percentage match score based on relevant keyword and skill overlap.
* 🔍 **Skill Gap Analysis**: Identifies missing critical skills required by the job description.
* 💡 **Smart Recommendations**: Suggests targeted resume improvements to increase ATS visibility and recruiter relevance.
